# 知识库问答测试题库

覆盖当前系统里全部 6 家企业、14 个知识库（不含空库/仅 1 篇文档的边角库）。题目直接取材自各知识库实际收录的文档内容（2026-08-24 从 Chroma 里现查出来的），不是凭空编的，方便对照回答是否准确。

题目按四种类型标注：
- **【单跳】**：明确指定了部门/枢纽等限定词，答案应该唯一、精确。
- **【歧义】**：语料里同一类政策在不同部门/枢纽下有不同数字（故意做的近似重复 chunk，测试检索精度和模型会不会张冠李戴），提问时**不指定**限定词，观察系统怎么处理——是追问澄清、列出所有部门的数字、还是随便挑一个当成唯一答案。
- **【幻觉探针】**：问一个语料里根本不存在的部门/枢纽/产品/数字，正确行为是如实说未检索到，不能编。
- **【跨库】**：需要综合同一企业内两个不同知识库的内容才能回答。
